# XVF3800 firmware parameters - firmware 2.0.9+, 48kHz USB audio
#
# These settings are saved to flash via SAVE_CONFIGURATION and survive reboots.
# Re-apply manually after a firmware upgrade using:
#   /opt/reSpeaker/xvf_host -e /opt/reSpeaker/init_commands.txt
#   /opt/reSpeaker/xvf_host SAVE_CONFIGURATION 1
#
# The udev rule no longer runs this automatically on device connect.
#
# 2026-07-13: outputs switched to the ASR path (category 7: post AEC+beamformer,
# NO post-processor) after the A/B experiment — the PP path (6 3) both created
# false positives (AGC pumping quiet transients to speech-like energy) and
# chopped voice-over-radio (NLP). All PP_* tuning removed: nothing consumes the
# PP output anymore. L = application input (ASR, auto-select beam),
# R = far-end reference with system delay (AEC diagnostics; lets a stereo
# recording correlate triggers with our own playback).

AUDIO_MGR_OP_L 7 3
AUDIO_MGR_OP_R 5 0
AEC_ASROUTONOFF 1
AEC_ASROUTGAIN 4.0
AEC_HPFONOFF 4
AUDIO_MGR_REF_GAIN 8
AUDIO_MGR_MIC_GAIN 90
AUDIO_MGR_SYS_DELAY 12
